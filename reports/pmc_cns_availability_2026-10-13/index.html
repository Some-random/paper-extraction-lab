490,354 open-access PDF candidates across a selected set of 55 journal titles, including a historical predecessor. The user selected related journals as well as Cell, Nature and Science. These sets do not exhaust the publishers’ catalogues.

Excluding Scientific Reports gives 187,791 PDF candidates. This count has no biology-only or original-research-only filter; reviews, corrections and other article types can appear.

Official PMC ESearch counts checked October 13, 2026. Embargoed records are excluded. Counts were queried sequentially, so index updates can cause small differences between family sums and separately queried Boolean unions.

Single-GPU capacity scenarios

The existing nine-page diagnostic took 150.412 seconds on one H200 using the sequential Transformers BF16 runner: about 16.7 seconds/page. Extrapolations below exclude downloads, retries, initialization and downstream QA. They are planning scenarios, not measured whole-paper throughput.

The shared /data/rustfs1 filesystem currently has approximately 266 GiB free; this is not reserved space. At an assumed 5 MB/PDF, the 490,354-paper pool requires about 2.45 TB for PDFs alone, before XML, media and outputs.

Large-scale processing requires a storage plan and a measured serving benchmark. Keep source XML alongside PDFs for independent validation of olmOCR 2 output, retain paper versions and licenses, and preserve the frozen nine-page comparison separately.
