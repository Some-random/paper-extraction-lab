What the experiments showed

Native XML preserves labels, table spans, footnotes and explicit referring text. PDF layout extraction helps, but its output needs checks. Selective OCR repaired a difficult page; geometry checks caught an incorrect caption link.

Recommended route: native XML/HTML when available → native PDF text plus layout/table extraction → selective OCR or document VLM on failures → evidence validation → grounded QA.

Outputs and limits

The 36 questions/answers replay exactly from retained table cells or captions. They demonstrate evidence transport; no model was trained and no teacher reasoning was generated. The 27 binding records retain units, uncertainty and missing-measurement semantics.

Source pages accompany all preferred bundles. They are explicitly full pages; regional crops are optional because multi-panel figures and decorative regions remain ambiguous.

olmOCR, GLM-OCR and GROBID were researched but not run. The next useful test is a local document VLM on the flagged regions with these same source-based checks.
