# Maintaining the literature review

Edit [review.json](review.json), then run `python3 scripts/render_foundation_catalog.py` from the repository root. This produces the review, supporting pages, study pages and [numeric CSV](catalog.csv) from one registry.

The starter conclusion is separate from author-reported budgets. Its figures come from `starter_corpus_estimate.json`; reproduce those with `scripts/estimate_starter_budget.py` before rerendering. Keep inventory measurements, assumed retention and unbenchmarked runtime scenarios explicit in `source_planning.md`.

The `presentation` record selects the review section, starting checkpoint and one overview budget, with explicit content scope and quantity type. It must cite initialization evidence. Keep every original budget in `token_budgets`; selecting an overview row never changes a reported amount. CPT studies belong with CPT models regardless of publication type. Do not classify instruction tuning, contrastive learning or random initialization as CPT.

Overview entries also require `author_institutions`, `dataset_sources`, `paper_text_origins`, `modality_profile` and `paper_quality`. Preserve attribution sources and named inputs. Overall quality reviews cover contribution, soundness, evaluation, reproducibility and clarity, with primary-source links. Keep historical `evidence_assessment` records as provenance. Do not add modality totals to acquisition totals. The overview shows numeric modality counts and sorts by overall quality, with alphabetical ties. Optional modality display groups sum only disjoint, known component amounts; corpus composition records must reconcile with the selected total. Keep overview links in the Source column (one Paper link and one Notes link). Use a dash for unavailable category amounts and plain language for an unknown total. Keep detailed counting definitions on study pages, without dagger markers in the overview. Keep the processing recipe, concrete actions and supporting papers in `data_pipeline.md`; the catalog overview links to that page. A venue or institution name is not an overall-quality measurement. Record numerical allocation corrections explicitly in the token audit.

The [token audit](token_budget_verification.json) records numerical checks and source snapshots. [Archived references](archive.md) preserve earlier out-of-scope material.

Evaluation protocols, benchmark cases and runs live in the separate private [bio-evaluation repository](https://github.com/Some-random/bio-evaluation). This repository holds extraction work and public literature notes. Private evaluation links remain in the registry as provenance, not public review navigation.
